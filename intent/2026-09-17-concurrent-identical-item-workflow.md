# Intent: 동일 시험항목 동시분석 그룹의 워크플로우 동기화
Author: 사용자 요청/오케스트레이션 · Status: completed

## Problem
동시분석 그룹에 속한 품목의 시험항목 구성이 같은 경우에도 시험자가 한 배치의 항목을 시작하거나 완료할 때 다른 배치의 상태를 별도로 조작해야 한다. 반면 같은 시험을 수행해도 배치별 결과가 적합·부적합으로 갈릴 수 있으므로 판정과 그 이후 절차를 자동으로 묶으면 안 된다.

## Proposed outcome
시험항목 집합이 완전히 같은 그룹에서는 물리적으로 한 번 수행하는 항목 시작·완료·시작 취소만 그룹의 다른 배치에도 함께 반영된다. 적합·부적합 같은 결과 판정과 검토 시작·완료·반려·재실시, 승인 단계·승인은 배치별로 수행한다. 관리자가 명시적 그룹 검토·승인 버튼을 누르는 일괄 기능은 유지하되 각 배치의 개별 경로를 막지 않으며, 화면에 전파 범위를 명확히 표시한다.

## Affected users and systems
- 역할: 관리자 / 시험자 / 둘 다
- 화면: 내 작업, 작업 현황 및 QC 작업 상세·검토·승인 화면
- 테이블: `concurrent_analysis_groups`, `concurrent_analysis_group_items`, `qc_jobs`, `qc_job_items`, `qc_job_status_history`, 검토·알림 관련 테이블
- 확정(LOCK)·작업 시작 상태와의 관계: 기존 LOCK 및 승인·검토 이후 항목 수정 금지 규칙을 유지하고, 그룹 해제 뒤에는 그룹 전파 없이 각 배치의 현재 상태를 보존한다.
- 크론: `instrumentation.ts`의 PCT 적재 및 자동 작업에는 영향이 없다.

## Constraints
시험항목 집합은 그룹 내 취소·제외되지 않은 모든 배치의 항목을 이름 trim·중복 제거·순서 무관으로 정규화해 판정한다. N/A/제외 항목은 기존 적재 규칙상 `qc_job_items`에 생성되지 않은 항목으로 보며, 빈 집합은 동일로 보지 않는다. 제조번호별 시험 기록과 감사 이력은 각 작업에 별도로 남기며 기존 권한·장비 검증·낙관적 잠금 규칙을 변경하지 않는다.

## Open questions
- 결과 입력이 별도 기능으로 추가되는 경우 결과값·판정값을 짝 배치에 복사하지 않는 원칙을 어떤 화면 문구로 확장할지 결정한다.
