# Intent: AI 스케줄 오더 수정 서랍에서 수동 오더를 삭제할 수 있게 한다
Author: kyo (개발) · Status: completed
승인: 2026-09-15 사용자 사전 승인

## Problem
사용자 원문: "ai 스케줄 관리에 수동 오더된 내용에 대한 삭제 버튼이 없는데 오더를 클릭했을때 삭제 버튼이 취소 버튼 왼쪽 사이드에 생성해줘"

- 관리자가 잘못 등록했거나 필요 없어진 수동 오더를 지울 방법이 화면에 없다. 상태를 바꾸는 우회도 막혀 있어 목록에 계속 남는다.
- 자동 오더는 제조팀 시트에서 사라지면 적재가 알아서 삭제하지만, 수동 오더는 시트에 없으니 그 경로도 없다.

## Proposed outcome
- 오더 카드를 눌러 연 수정 서랍 하단에서, [취소] 버튼 왼쪽에 [삭제] 버튼이 보인다. 수동 오더이고 관리자일 때만 보인다.
- 삭제하려면 사유를 반드시 입력한다. 삭제된 오더는 목록·배정 대상에서 빠지고, 누가 언제 왜 지웠는지 수정 이력에 남는다.
- 기록은 지우지 않는다(삭제 상태로만 바꾼다).
- 시험이 이미 시작됐거나 확정(LOCK)된 오더는 삭제할 수 없고, 버튼에 그 이유가 보인다. 서버도 같은 기준으로 거절한다.

## Affected users and systems
- 역할: 관리자만. 시험자는 영향 없음(삭제된 오더가 할 일에서 빠질 뿐).
- 화면: `/schedule/orders` 오더 수정 서랍 하단
- 테이블: `pct_orders`(상태·삭제 시각), `pct_order_edits`(사유 이력), `concurrent_analysis_group_items`·`concurrent_analysis_groups`(그룹에서 빼기)
- 확정(LOCK)·작업 시작 상태와의 관계: LOCK·작업 시작 오더는 삭제 불가 — 원칙 2·3 을 그대로 지킨다.
- 크론: PCT 적재는 수동 오더를 매칭하지 않으므로 영향 없음. 장비 대기 자동취소 크론 영향 없음.

## Constraints
- 자동 적재 오더는 이 버튼으로 지우지 않는다(시트가 원본).
- 행 삭제 금지 — GMP 이력 보존을 위해 삭제 상태로만 바꾼다.
- 사유 없는 삭제 금지.
- 삭제된 수동 오더가 수동 오더였다는 표시를 잃지 않아야 한다.
- 데이터 수정 UX 는 모달/서랍, 한국어 문구, 디자인 규칙을 따른다.

## Open questions
- 삭제한 수동 오더를 되살리는(복구) 화면이 필요한가. 지금은 목록의 '삭제' 상태 필터로 보기만 할 수 있다.
- 삭제된 수동 오더는 중복 기준(네 값)에서 빠져 같은 값으로 다시 등록할 수 있게 했다(0052). 그런데 0052 적용 전에는 옛 제약 때문에 막힌다 — 적용이 늦어지면 안내가 충분한가.
- 담당자가 지정된 수동 오더를 지울 때 담당자에게 알림을 보내야 하는가.
